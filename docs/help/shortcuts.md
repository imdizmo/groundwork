# Keys and mouse

The keys work in the 3D editor, not while typing in a box (`F1` works everywhere). On a Mac, `Cmd` stands for `Ctrl`
and `Option` for `Alt`.

## Camera

| Key or mouse | Action |
|---|---|
| Right drag | Turn the view. |
| Wheel | Zoom. |
| Middle drag, `Space` + left drag | Slide the view. |
| `W` `A` `S` `D`, arrows | Move around. |

## Panels and saving

| Key | Action |
|---|---|
| `V` | View panel. |
| `L` | History. |
| `?` or `F3` | The help card. |
| `F1` | Help at the page of the tool in use. |
| `Ctrl+Space` | The objects drawer. |
| `Ctrl+S` | Save the map. |

## Tools

| Key | Tool |
|---|---|
| `E` | Select |
| `1` `2` `3` `4` `5` | Raise, Lower, Flatten, Smooth, Restore |
| `0` | Natural |
| `O` | Erode |
| `6` `7` `8` `9` | Paint layer 2, 3, 4, and layer 1 (take paint off) |
| `M` | Measure |
| `H` or `Esc` | View |

## Undo, copy and paste

| Key | Action |
|---|---|
| `Ctrl+Z` | Undo. |
| `Ctrl+Y`, `Ctrl+Shift+Z` | Redo. |
| `Ctrl+C` / `Ctrl+X` | Copy / cut the selection. |
| `Ctrl+V` | Paste. |
| `[` / `]` | Brush 1 m smaller / bigger. |

The Select tool's own keys are on [Select](../select.md#shortcuts).
